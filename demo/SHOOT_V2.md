# V2 拍摄手册 · 「让 AI 当面拆穿一条爆款视频」

> 概念：不念文档。核心戏剧冲突 = **工具初判 51% AI → agent 看图复核纠正为 97% 实拍**。
> 成片目标 65 秒。录制约 40 分钟（含一次真实 Hermes 交互 6 分钟）。
> 配套素材：`demo/evidence_compare.png`（证据对比图，已生成）、`demo/sample_report/`（成品报告）。

---

## 录制顺序（按场景分组，不是成片顺序）

### SESSION 1 ｜ 真实交互录屏（先录，机器跑的时候你歇着）

**开始录屏前**：终端字号 ≥16pt、暗色主题、窗口 16:9。

| # | 操作 | 你要说的话（画外音，可后期配） | 预期画面 |
|---|---|---|---|
| S1 | 终端粘贴并回车：`hermes -z "用 rea-video 插件拆解 /Users/mac/Documents/workspace/github/rea-video/docs/cases/videos/unboxing.mp4，低置信镜头请自己看图复核后再给结论"` | （可不配，或一句"开始了"） | 命令行开始滚动 |
| S2 | 等待全流程跑完（拆解 + agent 看图复核，约 3–6 分钟；UVR 模型已缓存） | — | 工具调用滚动；**不要剪掉失败或重试**，真实的更可信 |
| S3 | 跑完后打开报告：`open ~/Movies/demo_raw_prerun/unboxing_report_v2/report.html`（或 Hermes 给出的路径），慢速滚动到底 | — | 报告全貌 |

> ⚠️ 如果 Hermes 复核后结论仍是"AI 为主"而不是"实拍为主"——**照样录**，那反而是更真实的素材：说明低置信场景下 agent 的判断也有边界，demo 里如实说即可。不要挑结果，录过程。

### SESSION 3 ｜ 画外音配音（对已成片画面念，不露脸）

| # | 画面 | 口播 |
|---|---|---|
| C1 ｜ 证据对比图全屏（`demo/evidence_compare.png`，缓推 2 秒） | **看左边**：工具给的理由，全是纹理统计——噪声、用色数、平坦块。说白了，就是掷硬币。 |

## 成片装配顺序（给剪辑，约 65 秒）

```
B1a 钩子(10s) → S1-S2 交互录屏跳剪(12s) → C1+ C2 证据对比(10s) → C3 复刻方案(8s) → S4 结论镜头(8s) → B2 CTA(12s)
```
黄字卡节点：`51% AI` → `掷硬币` → `看图复核 97% 实拍` → `复刻方案` → `仓库链接`
